### 1.1 左侧边栏：配置菜单

| 板块 | 内容 |
|------|------|
| 通用项目设置 | 项目名称、站点列表管理、前端分离策略、AdSense 绑定 |
| AI模型与API配置 | 模型切换（MiMo/DeepSeek/Ollama）、API Key、Token 监控、温度参数 |
| 内容生产配置 | 每日文章数量、关键词模式、7阶段参数、风格模板 |
| 增长黑客配置 | 推广集群管理、平台白名单、频率参数、108好汉身份池 |
| 监控与风险 | 风控阈值、飞鸽速度、自动备份 |
| 系统设置 | 主题切换（水墨强度）、通知方式、数据导出 |

### 1.2 中间主区域：两大场景（页签切换）

**页签1：宋徽宗写作工厂（编制内内容生产）**

场景：宋代大型书房/驿站大堂
- 7张长桌，对应7个阶段
- 每张桌坐着对应历史名人（原地不动）
- **小兵（驿卒）在桌间走动搬运竹简**（类似 Marvis 的小牛马）
- 飞鸽在桌子间穿梭
- 每个环节显示完成率、进行中、报错状态

**页签2：宋江108好汉分发大厅（编外推广）**

场景：圆形布局
- 外圈：108好汉按天罡36+地煞72分两层，围成圆形
- 内圈：32个平台图标（顺时针排列）
- 圆心：总控图标（宋徽宗印章）
- 信鸽从好汉位置沿**顺时针螺旋轨迹**飞向内圈平台图标
- 信鸽带**灰色渐隐尾迹**（最近3秒路径，80%→0%）

### 1.3 右侧边栏：数据概览

| 板块 | 内容 |
|------|------|
| 总数据看板 | 今日飞鸽数、总文章产出、AdSense 预估收入 |
| 写作场景指标 | 各阶段完成率、平均耗时、质检通过率 |
| 推广场景指标 | 各平台推广量、转化率、异常身份预警 |
| 风险雷达 | 全局风险 + 系统健康度 |

## 四、信鸽飞行系统

### 4.1 飞行轨迹

| 轨迹类型 | 视觉效果 | 适用场景 |
|---------|---------|---------|
| **顺时针螺旋**（默认） | 信鸽从好汉位置出发，沿螺旋路径飞向内圈平台图标 | 常规推广 |
| **直线+尾迹** | 信鸽直线飞出，身后带灰色渐隐尾迹 | 紧急推广/限时任务 |

### 4.2 信鸽状态

| 状态 | 视觉效果 | 含义 |
|------|---------|------|
| 正常飞行 | 白色信鸽，快速扇翅，叼着竹简 | 正在投递 |
| 被射落 | 信鸽中箭，羽毛散落粒子效果，坠落 | 平台拒绝/账号被封 |
| 成功到达 | 信鸽到达平台图标后消失，平台图标闪烁绿色 | 投递成功 |

### 4.3 灰色尾迹规格

```
好汉位置 → [灰色渐隐螺旋线] → 平台图标
尾迹长度：最近3秒的飞行路径
透明度：从80%渐隐到0%
颜色：浅灰色(#95a5a6)
```

## 五、小兵（驿卒）系统

### 5.1 设计原则

- 7位领导**原地不动**，由小兵负责走动搬运
- 类似 Marvis 中的小牛马角色
- 小兵是Q版宋代士兵造型，比领导人物小一号

### 5.2 小兵动作

| 场景 | 小兵动作 | 触发条件 |
|------|---------|---------|
| 传递竹简 | 小兵抱着竹简从A桌走到B桌，放下后返回 | 流水线阶段切换 |
| 取回结果 | 小兵从完成的桌旁取走竹简，送到下一环节 | 阶段完成 |
| 报信 | 小兵跑步前进（比走路快），表情焦急 | 报错/紧急事件 |
| 巡逻 | 小兵在7张桌子之间按固定路线巡逻 | 空闲状态 |

### 【后续再说】

| 动画 | 描述 | 原因 |
|------|------|------|
| 信鸽疲惫飞行 | 低垂翅膀慢飞 | 低优先级 |
| 信鸽返航 | 从平台飞回好汉 | 低优先级 |
| 好汉排队中 | 踮脚张望 | 低优先级 |
| 好汉被限流 | 蹲下抱头+⚠️ | 低优先级 |
| 好汉协作中 | 背靠背放飞信鸽 | 实现复杂 |
| 搜索排名风向标 | 古代风向标 | 用户感知弱 |
| 关键词种子发芽 | 新关键词发芽 | 概念好但低优 |
| 隔离墙/巡逻卫兵 | 皇城司安全可视化 | 阶段三才需要 |
| 季节装饰/节日彩蛋 | 桃花/雪花/爆竹 | 趣味性非核心 |
| 收支流水小溪 | 资金流动可视化 | 实现复杂 |
| 驿丞切换动画 | 换模型时人物变化 | 低频操作 |
