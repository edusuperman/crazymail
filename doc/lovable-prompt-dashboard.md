# Lovable Prompt — CrazyMail Dashboard（大宋宣和驿站）

## 项目概述

创建 CrazyMail 的内部运营 Dashboard —— **大宋宣和驿站**。这是一个独立应用（不与 tempmails.top 混在一起），用于可视化管理临时邮箱矩阵的所有运营数据。

**核心定位**：所有数据通过 API 获取，所有操作通过后端执行。

## 设计文档

请严格按照 `crazymail_docs/modules/VISUALIZATION.md` 的设计规范开发。

## 技术栈

- **框架**：Next.js 15（App Router）+ TypeScript
- **UI 库**：shadcn/ui + Tailwind CSS
- **动画引擎**：PixiJS 8.x（角色动画、信鸽飞行、粒子效果）
- **流程图**：React Flow（LangGraph 可视化）
- **状态管理**：Zustand
- **部署**：Vercel

## 整体风格

**国风大宋驿站** —— 水墨 + 可爱卡通风格

- 配色方案：
  - 墨黑 `#1a1a1a` — 背景、标题
  - 朱红 `#c0392b` — 强调、警报
  - 帝金 `#d4a017` — 高亮、Premium
  - 玉绿 `#2e7d5e` — 正常状态
  - 宣纸色 `#f5f0e8` — 卡片背景
  - 墨蓝 `#2c4a6e` — 辅助色
- 参考：腾讯 Marvis UI（等距3D办公室）的清晰、直白、强视觉反馈
- 但全部替换为宋代国风驿站风格

## 中间主区域：两大场景（页签切换）

### 页签1：宋徽宗写作工厂（编制内内容生产）

**场景**：宋代大型书房/驿站大堂

**布局**：
- 7张长桌，对应7个阶段
- 每张桌坐着对应历史名人（原地不动）
- **小兵（驿卒）在桌间走动搬运竹简**
- 飞鸽在桌子间穿梭

**7位历史名人**：

| 角色 | 职能 | 桌上道具 | 执行中动画 | 报错动画 | 完成动画 |
|------|------|---------|-----------|---------|---------|
| 宋徽宗 | 总管/审批 | 龙椅+朱笔+竹简堆 | 坐堂批阅竹简，朱笔圈点 | 摔笔起身踱步，眉头紧锁 | 端坐龙椅，手抚竹简微笑 |
| 李清照 | 写作 | 书桌+毛笔+墨砚+纸张 | 奋笔疾书，墨汁飞溅 | 丢笔来回踱步，叹气 | 端坐书桌，手捧完成的词稿 |
| 岳飞 | 质检 | 帅案+放大镜+"精忠报国"旗帜 | 举放大镜逐字检查竹简 | 拍桌怒起，把竹简摔地上 | 严肃点头，盖"通过"大印 |
| 张择端 | 大纲/研究 | 画架+画卷+毛笔 | 铺开画卷勾勒框架 | 撕掉画卷揉成团重来 | 展开完成的画卷满意端详 |
| 李纲 | 策略/规划 | 沙盘+地图+令旗 | 在地图前插旗标注 | 拔掉旗子重新推演摇头 | 收起指挥棒双手背后站立 |
| 韩世忠 | 部署/发布 | 战马+号角+令箭 | 跨马扬鞭号令三军 | 拉住缰绳翻身下马检查 | 下马收刀抱拳行礼 |

- 传递竹简：小兵抱竹简从A桌走到B桌，放下后返回

- 巡逻：小兵在7张桌子之间按固定路线巡逻

**场景**：圆形布局

```
                    [好汉] [好汉] [好汉]
                [好汉]                   [好汉]
              [好汉]   [平台][平台][平台]   [好汉]
```

- 外圈：108好汉按天罡36+地煞72分两层，围成圆形
- 内圈：32个平台图标（顺时针排列）
- 圆心：总控图标（宋徽宗印章）

**32个平台分类**：
- 社媒（8个）：Facebook, Instagram, X/Twitter, TikTok, YouTube, Reddit, LinkedIn, Pinterest
- 短视频（4个）：快手, 抖音国际版, Snapchat, Threads
- 新闻/博客（6个）：Medium, Substack, WordPress, Blogger, Hacker News, Product Hunt
- 技术论坛（6个）：Stack Overflow, GitHub, Dev.to, V2EX, CSDN, 掘金
- 问答（4个）：Quora, Stack Exchange, 知乎, Yahoo Answers
- 独立站（4个）：tempmails.top, tempmails.io, tempmails.org, 20站总图标

**好汉动画状态**：

| 状态 | 动作 | 触发条件 |
|------|------|---------|
| 执行中 | 放下武器 + 放飞信鸽 | 正在向某平台发送推广内容 |
| 报错 | 丢掉武器 + 不断挠头 | 平台返回错误/限流/封号 |
| 终止 | 人物变灰 + 红白呼吸灯背景 | 任务被手动终止或严重异常 |
| 完成 | 原地坐下静止 | 推广任务成功完成 |
| 休息 | 丢掉武器 + 不断喝酒 | 等待下一个任务（空闲状态） |

## 信鸽飞行系统（核心动效）

### 飞行轨迹

| 轨迹类型 | 视觉效果 | 适用场景 |
|---------|---------|---------|
| 顺时针螺旋（默认） | 信鸽从好汉位置出发，沿螺旋路径飞向内圈平台图标 | 常规推广 |
| 直线+尾迹 | 信鸽直线飞出，身后带灰色渐隐尾迹 | 紧急推广/限时任务 |

### 信鸽状态

| 状态 | 视觉效果 | 含义 |
|------|---------|------|
| 正常飞行 | 白色信鸽，快速扇翅，叼着竹简 | 正在投递 |
| 被射落 | 信鸽中箭，羽毛散落粒子效果，坠落 | 平台拒绝/账号被封 |
| 成功到达 | 信鸽到达平台图标后消失，平台图标闪烁绿色 | 投递成功 |

### 灰色尾迹规格

```
好汉位置 → [灰色渐隐螺旋线] → 平台图标
尾迹长度：最近3秒的飞行路径
透明度：从80%渐隐到0%
颜色：浅灰色(#95a5a6)
```

## 关键原则

1. **纯展示层** — Dashboard 只显示数据，不触发任何真实操作
2. **国风风格** — 水墨 + 可爱卡通，不是现代科技风
3. **Marvis 式布局** — 清晰、直白、强视觉反馈
4. **飞鸽传书** — 核心动效，必须实现
5. **编制内 vs 编外** — 两个场景清晰分区
