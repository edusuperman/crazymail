# CrazyMail 前端国风实现超详细方案

## 1. 设计原则
- 严格遵守项目核心指令：纯展示层，不允许AI自主执行或跨站操作。
- 国风主题：疯邮·大宋宣和驿站（宋代青绿山水 + 水墨 + 卡通风格）。
- 编制内（朝廷官员，核心7阶段） vs 编外（108好汉，增长黑客）清晰分区。
- 飞鸽传书作为核心动效。

## 2. 技术栈（低成本高效果）
- Next.js 15 + TypeScript + Tailwind CSS + shadcn/ui
- PixiJS 8.x（飞鸽 + 粒子动画）
- React Flow + Mermaid（流程图）
- Three.js（可选轻3D驿站场景）
- Zustand（状态管理）

## 3. 页面结构
- **主大厅（宣和总驿）**：宋徽宗坐镇 + 20驿站网格 + 实时飞鸽监控
- **编制内区域**：7阶段历史名人卡片（李纲、张择端、李清照、岳飞等）
- **增长黑客大厅**：108好汉世界地图（全球分舵）
- **监控面板**：风险雷达（官府告示板）、AdSense银库、Gantt军令状

## 4. 飞鸽传书动效实现
- 使用PixiJS Sprite + 路径动画
- 状态：正常（快速直线）、缓慢（曲线摇晃）、风控（被箭射落 + 羽毛粒子）
- 批量起飞：108好汉同时放飞，视觉高潮

## 5. 角色可视化
- 编制内：历史名人形象（一对多管理）
- 编外：108好汉可爱卡通（一对多虚拟身份展示）

## 6. 实现步骤
1. 创建Next.js项目
2. 集成PixiJS飞鸽组件
3. 构建驿站网格和地图
4. 添加模型切换器（驿丞选择）
5. 部署到Vercel

## 7. 性能与合规
- 所有交互仅展示，不执行真实任务
- 移动端响应式支持
